================================================================================
                  STAFFCHAT NIGHTCUBE - SETUP GUIDE (v4)
================================================================================

This guide outlines the correct installation and configuration procedure for the
StaffChatNightCube plugin, specifically focusing on the multi-server Discord
integration.

--------------------------------------------------------------------------------
1. INSTALLATION
--------------------------------------------------------------------------------
   1. Upload `StaffChatNightCube.jar` to the `/plugins/` folder of ALL servers
      (Proxy, Lobby, Survival, etc.).
   2. Restart all servers to generate the initial configuration files.

--------------------------------------------------------------------------------
2. CONFIGURATION (CRITICAL)
--------------------------------------------------------------------------------
   You must configure `config.yml` on each server individually.

   A. COMMON SETTINGS (All Servers):
      - `discord.token`: Paste your Discord Bot Token.
      - `discord.channel-id`: Paste the ID of the text channel for StaffChat.

   B. SERVER-SPECIFIC SETTINGS:
      - `server-name`: Give each server a unique name (e.g., "Lobby", "Build").

   C. THE "DISCORD HANDLER" RULE (Very Important):
      To avoid duplicate messages and API errors, only ONE server should handle
      Discord message processing (deleting user messages and reposting as webhook).

      - On your MAIN server (e.g., Lobby):
        Set `discord-handler: true`

      - On ALL OTHER servers (e.g., Build, Survival):
        Set `discord-handler: false`

--------------------------------------------------------------------------------
3. DISCORD BOT REQUIREMENTS
--------------------------------------------------------------------------------
   Ensure your Discord Bot has the following permissions in the channel:
   - [x] View Channel
   - [x] Send Messages
   - [x] Manage Messages (Required to delete original user messages)
   - [x] Manage Webhooks (Required to post as the user)
   - [x] Message Content Intent (Enabled in Developer Portal)

--------------------------------------------------------------------------------
4. TROUBLESHOOTING
--------------------------------------------------------------------------------
   - Messages duplicating? -> Check that only ONE server has `discord-handler: true`.
   - Bot not deleting messages? -> Check "Manage Messages" permission.
   - "Invalid Form Body" error? -> Ensure nicknames don't contain "Discord" or invalid chars.

================================================================================
